# BunnyHop Skin Asset Prompts

## 공통 스타일 가이드

기존 에셋 참조: 3D rendered, soft clay/plush toy aesthetic, cute chibi proportions (big head, small body), front-facing view, transparent background, soft lighting, no outline.

### 공통 프롬프트 프리픽스
```
3D rendered cute chibi character, soft plush toy aesthetic, front-facing, transparent background (PNG), soft studio lighting, no outline, game sprite asset, 128x128 pixels
```

### 아이템 공통 프리픽스
```
3D rendered game item icon, soft realistic texture, transparent background (PNG), soft studio lighting, centered, 64x64 pixels
```

### 포즈 가이드
- **idle**: 정면, 양팔 살짝 내림, 입 다문 귀여운 표정, 눈 동그랗게
- **jump**: 정면, 양팔 살짝 위로, 입 벌려 웃는 표정, 위로 튀어오르는 느낌
- **fall**: 정면, 양팔 양옆으로 벌림, 놀란 표정(눈 크게, 입 O모양), 아래로 떨어지는 느낌

## 생성 시 주의사항

1. **투명 배경 필수** — 게임에서 캔버스 위에 그리므로 배경 없어야 함
2. **일관된 크기/비율** — 모든 캐릭터가 비슷한 크기로 렌더링되어야 함
3. **정면 뷰** — 게임이 정면 뷰만 사용
4. **기존 토끼와 동일한 3D 스타일** — clay/plush toy 미학 유지
5. **포즈 구분 명확** — idle(차분), jump(신남), fall(놀람) 감정이 확실히 드러나야
6. **아이템은 당근과 비슷한 크기감** — 너무 크거나 작지 않게
7. **파일 형식**: WebP (lossy, quality 80-85)
8. **파일 구조**:
   ```
   public/assets/skins/{skin_id}/
     idle.webp      (128x128)
     jump.webp      (128x128)
     fall.webp      (128x128)
     item_normal.webp (64x64)
     item_special.webp (64x64)
     thumb.webp     (64x64)
   ```
