## 한국어

탱탱소프트(이하 "회사")는 「무한의당근」(이하 "앱") 이용자의 개인정보를 중요시하며, 「개인정보 보호법」 및 관련 법령을 준수합니다.

### 1. 수집하는 개인정보 항목

회사는 서비스 제공을 위해 아래 정보를 수집합니다.

| 구분 | 수집 항목 | 수집 목적 | 보유 기간 |
|------|-----------|-----------|-----------|
| 필수 | 닉네임 | 랭킹 시스템 표시 | 서비스 이용 종료 시까지 |
| 필수 | 게임 점수 | 랭킹 시스템 운영 | 서비스 이용 종료 시까지 |
| 선택 | Google 계정 프로필(이름, 이메일) | 소셜 로그인 시 본인 확인 | 서비스 이용 종료 시까지 |
| 자동 | 광고 식별자(GAID) | 맞춤 광고 제공 | 수집일로부터 1년 |
| 자동 | 기기 정보, OS 버전 | 서비스 최적화 및 오류 분석 | 수집일로부터 1년 |

### 2. 개인정보의 저장 및 관리

수집된 개인정보는 Supabase 클라우드 데이터베이스(서울 리전, 한국)에 안전하게 저장·관리됩니다. 데이터 전송 시 SSL/TLS 암호화를 적용합니다.

### 3. 개인정보의 제3자 제공

회사는 아래와 같이 제3자에게 개인정보를 제공합니다.

| 제공받는 자 | 제공 항목 | 제공 목적 |
|-------------|-----------|-----------|
| Google AdMob | 광고 식별자, 기기 정보 | 앱 내 광고 표시 |
| RevenueCat | 구매 정보, 기기 식별자 | 인앱결제 처리 및 구독 관리 |

### 4. 아동의 개인정보 보호 (COPPA 준수)

회사는 만 13세 미만 아동의 개인정보를 의도적으로 수집하지 않습니다. 만 13세 미만 이용자의 개인정보가 수집된 사실을 인지한 경우, 해당 정보를 즉시 삭제합니다. 보호자가 자녀의 개인정보 수집 사실을 알게 된 경우 아래 연락처로 문의해 주시기 바랍니다.

### 5. 이용자의 권리

이용자는 언제든지 아래 권리를 행사할 수 있습니다:
- 개인정보 열람, 정정, 삭제 요청
- 개인정보 처리 정지 요청
- 계정 삭제 요청

요청은 아래 연락처로 이메일을 보내주시면 10일 이내에 처리합니다.

### 6. 개인정보의 파기

이용 목적이 달성되거나 보유 기간이 경과한 개인정보는 지체 없이 파기합니다. 전자적 파일은 복구 불가능한 방법으로 영구 삭제합니다.

### 7. 개인정보처리방침의 변경

본 방침이 변경될 경우, 앱 내 공지 또는 업데이트 노트를 통해 사전 고지합니다.

## English

TengtengSoft ("Company") values the personal information of users of "Endless Jump" ("App") and complies with the Personal Information Protection Act of Korea and applicable international regulations.

### 1. Personal Information Collected

| Category | Data Collected | Purpose | Retention |
|----------|---------------|---------|-----------|
| Required | Nickname | Display on leaderboard | Until service termination |
| Required | Game scores | Leaderboard operation | Until service termination |
| Optional | Google profile (name, email) | Social login identity verification | Until service termination |
| Automatic | Advertising ID (GAID) | Personalized advertising | 1 year from collection |
| Automatic | Device info, OS version | Service optimization and error analysis | 1 year from collection |

### 2. Data Storage and Security

Personal data is securely stored in a Supabase cloud database (Seoul region, South Korea). All data transmission is encrypted via SSL/TLS.

### 3. Third-Party Data Sharing

| Third Party | Data Shared | Purpose |
|-------------|------------|---------|
| Google AdMob | Advertising ID, device info | In-app advertising |
| RevenueCat | Purchase info, device identifier | In-app purchase processing and subscription management |

### 4. Children's Privacy (COPPA Compliance)

We do not knowingly collect personal information from children under 13. If we become aware that we have collected personal information from a child under 13, we will delete it immediately. If a parent or guardian becomes aware that their child has provided personal information, please contact us at the address below.

### 5. User Rights

Users may exercise the following rights at any time:
- Request access to, correction, or deletion of personal data
- Request suspension of data processing
- Request account deletion

Please send requests via email. We will process requests within 10 business days.

### 6. Data Deletion

Personal data is permanently deleted when its purpose has been fulfilled or retention period has expired. Electronic files are destroyed using irreversible methods.

### 7. Policy Changes

Any changes to this policy will be notified through in-app notices or update notes prior to taking effect.
