## 콘텐츠 등급 설문 체크리스트

Play Console > 콘텐츠 등급 설문(IARC) 작성 시 아래를 참고하세요.

### 폭력성
- [ ] 사실적 폭력: **없음**
- [ ] 만화적/판타지 폭력: **없음** (캐릭터가 떨어지면 게임 오버되지만, 피/부상 묘사 없음)
- [ ] 자기 자신에 대한 폭력: **없음**

### 성적 콘텐츠
- [ ] 누드: **없음**
- [ ] 성적 콘텐츠: **없음**
- [ ] 성적 테마: **없음**

### 욕설 / 불쾌한 언어
- [ ] 비속어: **없음**
- [ ] 유머의 종류: **전연령 적합**

### 약물 관련
- [ ] 약물/알코올/담배 관련: **없음**

### 도박
- [ ] 시뮬레이션 도박: **없음**
- [ ] 실제 도박: **없음**

### 광고
- [ ] 앱 내 광고 포함: **예**
  - 배너 광고 (AdMob)
  - 전면 광고 (AdMob, 게임 오버 시)
  - 리워드 광고 (AdMob, 부활 시 선택적)
- [ ] 광고 내용 제어 여부: Google AdMob 정책에 따라 부적절한 광고 필터링됨

### 인앱결제
- [ ] 인앱결제 포함: **예**
  - 광고 제거 (일회성 구매)
  - 캐릭터 스킨 (일회성 구매)
- [ ] 가입/구독: **없음**

### 사용자 상호작용
- [ ] 사용자 간 직접 소통: **없음** (채팅, 메시지 없음)
- [ ] 사용자 생성 콘텐츠: **닉네임만** (랭킹 표시용, 검열 필요)
- [ ] 위치 공유: **없음**
- [ ] 소셜 미디어 연동: **없음**

### 개인정보
- [ ] 개인정보 수집: **예** (닉네임, 점수, 광고 ID)
- [ ] 개인정보처리방침 URL 등록 필요: **예**

### 데이터 보안
- [ ] 데이터 암호화 전송: **예** (SSL/TLS)
- [ ] 데이터 삭제 요청 가능: **예**

## 참고 사항

1. 광고 포함 시 "광고 포함" 배지가 스토어에 표시됩니다.
2. 인앱결제 포함 시 "인앱 구매" 배지가 표시됩니다.
3. 닉네임은 사용자 생성 콘텐츠로 간주되므로, 부적절한 닉네임 필터링 시스템이 권장됩니다.
4. COPPA 준수가 필요하며, 이는 개인정보처리방침에 명시되어 있습니다.
